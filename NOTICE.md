(https://github.com/RocketGod-git/Wardrive-Go, snapshot of build 2.0.34),
licensed under the GNU General Public License v3.0. This fork is licensed under
GPL-3.0 as well; see LICENSE.

## Changes from the original
- Renamed to Wardrive Lite, new application ID `com.shok3r.wardrive`.
- SHOK3R art (app icon, logo), SHOK3R / Kraken / Memphis Night skins (default SHOK3R),
  Chakra Petch headline font (SIL OFL).
- Removed WPA hash capture (PMKID / handshake harvesting and cracking links).
- Update checker points at this repository's releases.
- Added Wardrift upload, extra Flock / Raven / Penguin detections and an ESP32 firmware
  flasher (see git history for details).

Fonts: Chakra Petch, Share Tech Mono (SIL Open Font License 1.1).
Flock / Raven signatures: Flock You by colonelpanichacks (MIT).
